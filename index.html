        手順

        1. 下のボタンを押す。Googleのログイン画面が出たら、Gmailのアドレスとパスワードで入る。

          AI Studio を開く

        2. 初めてだと利用規約の画面が出る。チェックを入れて「続行」（Continue）。

        3. 「APIキーを作成」（Create API key）という青いボタンを押す。

        4. 「プロジェクト」を聞かれたら「新しいプロジェクトで作成」（Create API key in new project）。名前を聞かれたら何でもいい（例：sakelog）。

        5. 「AIza」で始まる長い文字が出る。横の「コピー」（四角が2つ重なったマーク）を押す。これがキー。

        6. 酒ログに戻って ⚙︎ →「ラベル読み取り」の枠を長押し →「ペースト」→「保存」。「設定済み（••••1234）」と出たら完了。

        Create API key＝APIキーを作成、Copy＝コピー。それだけ覚えれば足りる。

        無視してOK。カード登録はしなくていい。

        貼ったのに「キーが違うみたい」と出る
        前後に空白が入ってることが多い。もう一度コピーし直して貼る。

        「読めなかった」が続く
        その日の無料枠を使い切っただけ。翌日また使える。

        よくある心配

        お金かかる？
        無料枠がある。ラベル1枚の読み取りは0.1円くらいの計算で、無料枠の中ならゼロ。課金は自分でONにしない限り始まらない。

        キーはどこに保存される？
        この端末の中だけ。アプリの作者にも見えない。バックアップにも入らない。

        写真はどこに行く？
        読み取りのときだけGoogleに送られる。無料枠では、送った内容がGoogleのサービス改善に使われることがある。ラベルの写真なら気にしなくていいけど、人が写った写真は送らないほうがいい。

        漏れたら？
        AI Studio のページでそのキーを削除して、作り直せばいい。
